# CartFlow Documentation

This directory contains the architecture and planning documents for CartFlow.

- `architecture.md`: cloud architecture, layering, security posture, and response standards.
- `database.md`: DynamoDB access patterns and item design.
- `api.md`: HTTP API contract.
- `dependencies.md`: planned dependency groups.
- `environment.md`: environment variable specification.
- `folder-structure.md`: repository layout.
- `implementation-sequence.md`: phased delivery plan.
- `infrastructure.md`: Serverless Framework and AWS resource documentation.
